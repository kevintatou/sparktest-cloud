# Archived frontend features

This folder contains feature surfaces removed from the SparkTest Cloud MVP.
They are kept for reference only and must not be imported by active app code.

Archived for the MVP:

- Executors
- Suites
- CI / schedules
- Routing
- Insights / artifacts
- Security roles and API keys
- Experimental billing plans UI

To restore one of these features, move it back into the active component tree,
wire a production happy path, add tests, and make sure it belongs in the
first-level product navigation.
